# Міні-готель «Family Люкс»

Live site: https://familylux.hotelup.work

## About
Family Люкс — апарт-готель (`aparthotel`) у Кам’янці-Подільському, Жванецьке шосе, 2А. Сторінка продає APARTMENT FREEDOM + HOTEL CONVENIENCE за формулою STAY · COOK · FAMILY · RELAX; кампанійний рядок «Своя кухня. Свій ритм. Свій Кам’янець.» Бренд family-friendly, але не family-only. «Люкс» не використовується як luxury-твердження.

## Amenities (verified, list.json)
- Кухня (без переліку техніки — «уточнюйте для обраного помешкання»), кондиціонування, приватна ванна кімната
- Сімейні номери (без місткості й дитячих зручностей)
- Можна з тваринами (умови — за телефоном)
- Зона відпочинку просто неба, пікнік-зона, BBQ-зона (без обіцянок щодо гриля й палива)
- Безкоштовний Wi-Fi, безкоштовна парковка на території, трансфер з/до аеропорту (без ціни, не «безкоштовний»)
